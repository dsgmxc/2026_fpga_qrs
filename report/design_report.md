## 1. 选题背景与创新点

> **指南要求**:为什么选这个题目,它解决了什么实际问题,前人做过什么。

### 1.1 实际问题 🚧

- MOSFET 寄生电容(Cgs / Cgd / Cds)是功率器件与模拟电路设计的关键参数
- 传统 C-V 表征依赖商用 LCR 表 / 半导体参数分析仪 —— **设备昂贵、不便携、难以在线监测**
- 功率器件的老化与失效往往先体现在寄生电容的漂移上,**在线监测有明确的工程价值**

### 1.2 前人工作 🚧

- 阻抗法 / 自动平衡桥
- 电荷放大法(商用 C-V 表经典做法)
- 准静态 C-V(QSCV)
- **待补**:具体文献与商用方案对比

### 1.3 创新点 🚧

> 对应评分项「创新性与应用价值」**30%** —— 权重最高,务必充分论证。

- [ ] 低成本方案(对比商用仪器的价格量级)
- [ ] **跨学科选题**:从半导体器件表征 / 可靠性监测切入(指南 3.3.2 明确鼓励"从 FPGA 之外的学科中寻找题目")
- [ ] 数字锁相放大器替代模拟锁相 —— 参数可配、无温漂、可重构
- [ ] 硬件内嵌阻抗反演的实时性
- [ ] AI 辅助器件退化识别
- [ ] **待补**:量化对比

## 2. 设计原理与功能框图

> **指南要求**:设计原理与功能框图。

### 2.1 测量原理 🚧

**阻抗法 + 正交锁相解调**

```
           ┌─ Ch_A: V_dut
AC源 ─[R_ref]─┬── DUT ── GND
              └─ Ch_B: V_src

Z_dut = R_ref · V_dut / (V_src − V_dut)
Y = 1/Z_dut  →  Cp = Im(Y)/ω ,  Rp = 1/Re(Y) ,  D = tanδ
```

### 2.2 相干采样设计 🚧

```
f_s = f_clk / D                   (ADC 采样率,整数分频)
M   = round(2^B · f_e / f_s)      (NCO 相位增量)
条件: R / f_s = k / f_e           (k 整数 → 平均窗覆盖整数个激励周期)
```
满足后 2f_e 谐波被 CIC 精确抵消(零点落在 2f_e),频谱泄漏为零。

## 3. 软硬件划分依据与接口设计

> **指南要求**:软硬件划分依据与接口设计。

### 3.1 划分依据 🚧

| 层 | 模块 | 为什么放这一层 |
|---|---|---|
| PL-RTL | `cv_sys` `cv_axi_lite_slave` `spi_master` `dac_1220` `ad9833_spi` `nco` `adc_capture` `relay_ctrl` `meas_fsm` `cdc_sync` | 总线 / 状态机 / 接口 / 时序 —— 需要确定性时序与手工控制 |
| PL-HLS | `dlia_core` `cordic_polar` | 数据通路 —— 需要快速参数空间探索 |
| PS | `cv_monitor.py`(S1)`sweep.py`(S2)`calibrate.py`(S3)`baseline.py`(S4)`anomaly_model.py`(S5) | 无实时性要求 —— 编排、反演、校准、AI、可视化 |

> 📌 PS 侧编号用 `S1`–`S6`(`P1`–`P6` 保留给项目阶段),见 `source_design_checklist.md` §2.4。

### 3.2 接口设计 🚧

> **待补**:详见 `docs/interface.md`(寄存器映射表 / 引脚分配 / 时序约束)

### 3.3 继电器时序状态机 🚧

```
IDLE → SET_BIAS → BIAS_SETTLE → RANGE_SEL → RELAY_SETTLE
     → AC_ON → MEASURE → LATCH → AC_OFF → NEXT
                                    └→ FAULT(全断 + 栅极泄放)
```

**互锁要求**:禁止栅极悬空、禁止量程电阻短路,非法组合拒绝执行并置错误码。

### 3.4 安全设计 🚧

- MOSFET 栅极耐压保护(上电顺序、限流、钳位、泄放电阻)
- 过流 / 超时快速关断
