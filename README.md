## 目录对照说明

本项目采用《全国大学生嵌入式芯片与系统设计竞赛'2026 — FPGA 创新设计赛道选题指南(AMD)》**3.3.5.4 推荐目录结构**,各项对应关系如下:

| 目录 / 文件 | 内容 | 对应指南条目 |
|---|---|---|
| `README.md` | 项目简介与复现步骤 | 3.3.5.4 |
| `src/rtl/` | 手写 RTL 源码 | 3.3.5.1 工程包 |
| `src/hls/` | Vitis HLS 源码 | 3.3.5.1 工程包 |
| `src/python/` | PS 侧(PYNQ)软件 | 3.3.5.1 工程包 |
| `sim/` | 仿真或验证脚本与结果 | 3.3.5.1 工程包 |
| `sim/logs/` | 仿真原始日志(功能正确性的确认依据) | 3.3.5.1 工程包 |
| `build/` | 可复现的构建脚本 + 综合与实现报告 | 3.3.5.1 工程包 |
| `build/agent/` | 智能体工作流脚本 | 3.3.5.3 设计报告 |
| `board/` | 上板工程、运行脚本与实测输出 | 3.3.5.1 工程包 |

### 与推荐结构的差异

与指南 3.3.5.4 的推荐结构相比,本项目**仅新增 `docs/` 一个目录**,其余目录与推荐结构完全一致。

新增 `docs/` 的理由:该目录集中存放**器件与硬件的接口规格文档** —— 芯片命令与时序常量(如 DAC1220 的命令字、帧格式、`tXIN` 时序窗口)、开发板扩展口引脚表、量程与传递关系标定记录等。这些内容是设计报告「软硬件划分依据与接口设计」一节的**原始依据**,体量与更新频率都独立于报告正文,与 `report/` 混放会使报告正文被规格表淹没,也不便于脚本引用。

本目录的文件**均为纯文本**(Markdown / CSV),不含二进制数据,不依赖任何外部工具即可阅读。
