> **上表按 J4 脚号从 13 到 28 排列**(不是按位序),因为**整块 ADC 排线就插在这 16 个连续脚上**。
> 只有一个球号在 BANK34(`V13`,与 DDS 的 `T11` 同情形),其余 15 根在 BANK13 —— 两 bank 同为 3.3 V。

#### ⚠️ 一处**两文档互相矛盾**,已定位(球号无异议,脚号有)

工程 `led.xdc` 的注释里写了两组脚号:

```
D0..D11 = W11 Y11 Y12 Y13 V10 V11 W9 W10 Y8 Y9 Y6 Y7   (J4-26 .. J4-15)
PDN   = V6  (J4-21)   OTR  = W6  (J4-18)
```

拿本文件第 2 节的 J4 表逐条对:

- ✅ **`D0..D11` 那 12 条脚号全部对得上,而且严格单调**:W11=26、Y11=25、Y12=24、Y13=23、
  V10=22、V11=21、W9=20、W10=19、Y8=18、Y9=17、Y6=16、Y7=15 ⇒ **J4-26 一路倒数到 J4-15**,
  与注释里写的 `(J4-26 .. J4-15)` 逐字吻合。
- 🔴 **`PDN` / `OTR` 那两条对不上**:注释写 `V6 = J4-21`、`W6 = J4-18`,
  而本表读出来是 **`V6 = J4-14`、`W6 = J4-13`**。
  **J4-21 与 J4-18 在本表里是 `V11` 与 `Y8`,已经被 `adc_d[5]` / `adc_d[8]` 占着** ——
  一个球号不能同时接两个信号,所以**注释里的脚号是错的(球号没错)**。
- ✅ **改用 14 / 13 之后整块自洽**:J4-**13…28** 恰好是 **16 个连续脚**
  (13=OTR、14=PDN、15–26=D0..D11、27=CLK、28=OEB)⇒ 这才是一整块排针的实际插法。

📌 **处置**:按项目纪律 **球号才是约束依据**(`led.xdc` 正文用的就是球号,没有错),
**脚号只是注释** ⇒ **未改动工程里的 `.xdc`**,本表按上述推导填,请**接线时目视核对一次**。

> 📌 **可复用的判据(建议进 `skill/`)**:同一份注释里 **12 条全对、2 条全错** ——
> **"这份注释对过一次"不能推广成"这份注释可信"**,要逐条对。
> 而且这 2 条的错法很有特点:它们填的脚号**属于同表里另外两个已被占用的球号** ——
> ⇒ **凡是"脚号能对上另一个已知球号"的地方,一查就知道填错了**,不必等上板。

> ⚠️ **`adc_d[0]` 与 `adc_d[11]` 谁在两端没有第二条证据** —— 上面的位序完全照用户报的名单。
> 若实际接反,症状是**采样值位序整体倒置**(正弦会变成锯齿状的怪波形),一眼能看出来,
> 所以**上板第一件事就是看这个**。

## 四、已知陷阱

### 陷阱 1 ⛔ 「官方 XDC 里没有这个球号 ⇒ 板上没有这个脚」

**这是错的。** 官方 `NAVIGATOR_ZYNQ_IO.xdc` **只覆盖板载外设**,
扩展口(J3/J4)上的引脚**本来就不在其中**。

开发指南原文:「上表列出了**除扩展口外**,开发板上所有 PL 功能外设所对应的 IO 引脚号,
关于扩展口上的排针所对应的 IO 引脚号,大家可以参考开发板的原理图或者直接查看开发板上的丝印标注。」

**实际后果(2026-09-19 真实发生过)**:
`W13` / `Y14` 在官方 XDC 里叫 `cam_data[5]` / `cam_data[7]`,而 `W15` **在官方表里完全不存在**
→ 模型据此判断「这三个脚是摄像头专用,DAC 模块根本没接到」→ **误判,浪费了一轮排查**。
真相是**这三个脚同时引到了扩展口 J4 的第 32 / 34 / 36 脚**,底板网络名叫 `CMOS_D5` /
`CMOS_D7` / `CMOS_XCLK`(因为也接了摄像头接口),**正点原子把扩展口复用成了摄像头口**。

### 陷阱 2 ⛔ 拿 J3 的引脚表套 J4

两个扩展口的引脚表**不一样**。本文档只录了 J4。

### 陷阱 3 ⚠️ 相邻脚差一位

J4 第 31/33/35 脚分别是 `B34_L4_P` / `B34_L8_P` / `B34_L10_P`(网络名 CMOS_D6 / CMOS_PCLK /
CMOS_PWDN)—— 与第 32/34/36 脚**只差一位**,而且**在另一列**。
数错一列会让三根信号全落到错误的脚上,**现象与"没接"完全相同**。
上板前请**对板上的丝印**再确认一次。

### 陷阱 4 ⚠️ 这些脚同时接到板载摄像头接口

用 J4 的 27–36 脚时,若板上插了摄像头模块,**会与摄像头驱动信号冲突**。
本项目没有摄像头模块,不构成问题;但如果后续要同时用摄像头,必须重新选脚。
