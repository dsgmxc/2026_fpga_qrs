## 一、验收判据(事先定,事后不改)

> **界面把采样率拨到 65 MSPS → 点单点测量 → 屏上出波形。**

三条同时成立才算过:
1. `c_ui` 日志出现 `[mc] 采样 → 65.00 MSPS`(**回调真的执行了**);
2. 单点测量**返回结果**(不是"采集或解调失败");
3. 屏上结果页出现**波形**,而不是停在原页。

## 二、阻塞点:采样率回调的陈旧守卫

用户报「**点击没法选中啊**」——同页**激励行、相位行都点得动,只有采样率行没用**。

`ui_demo.c::UI_InitDivEvent()` 的守卫写成 `index > 5u`,
而**该行有 6 档**(65 MSPS 是第 6 颗),`user_data` 装的是"下标 + 1"
⇒ 65 MSPS 传进来 `index = 6` ⇒ **当场静默 `return`**:
触摸有事件、回调不执行、**无任何日志**。

同一页另两行的守卫恰好都对(激励 5 档配 `> 5u`、相位 3 档配 `> 3u`),
所以症状是**只有多档那一行失灵**。

**改动 = 一行**:`(index > 5u)` → `(index > 6u)`。
(就地留了注释,写明档位数在**五处**重复出现,改一处必须改五处。)

## 三、怎么定位的:量像素,不是看图

肉眼判"是不是点偏了"不可靠 —— 手的分辨力约 ±10 px,与"差一颗按钮"同量级。
改用**帧缓存转出的 PNG 做连通域分析**,把控件矩形直接量出来,取右列:

```
y=312  档位 5 颗  x = 264..382  392..510  520..638  648..766  776..894   ← 激励行
y=368  档位 6 颗  x = 264..361  371..468  478..575  585..682  692..789  799..896  ← 采样率行
y=424  档位 3 颗  x = 264..468  478..682  692..896                        ← 相位行
```

⇒ **65 MSPS 那颗按钮实测范围 `x 799..896, y 368..412`**;
触点 `(816,381)`(以及先前失败那次的 `877` / `880`)**都在按钮内部**
⇒ **"点偏了"排除**,缺陷在回调侧。

📌 **版面本来就是 6 档** —— 屏上明明画着 6 颗按钮,只有守卫还停在 5。
**"界面画对了"和"回调收得下"是两件事,视觉上完全看不出来。**

## 四、实测结果

### 4.1 采样率切换(日志原文)

```
[mc] 采样 → 65.00 MSPS(DIV=2,PH_OFF -2 → -1,窗 [-1,-1])
```

⭐ `PH_OFF -2 → -1` 与 `窗 [-1,-1]` —— 与 `LLM-053` 推出的
**`P=2` 折回**(`cv_adc_phase_center(2) = -1`、`adc_window(2) = [-1,-1]`)逐位一致。
这是那组 C 侧改动的**第三条独立证据**(前两条:静态对拍 9/9、板上 `0x90` 置位)。

### 4.2 偏压下发

```
[proto] 偏压 → 5.00 V  (0x14 = 0x86666,模块级 0.500 V ×10)
```

### 4.3 单点测量(验收核心)

```
[proto] 点测 CISS @ 5.00 V:偏压已下发,300 ms 后采一次(波形进结果页)
[adc] 单点  偏压 5.000 V
           | A/INA tick-1  幅值 0.0001 V,峰峰  5 码
           | B/INB tick+0  幅值 0.0090 V,峰峰 39 码
           | Cs 12942.154 pF(未标定) | OTR 0
```

| 项 | 值 | 判读 |
|---|---|---|
| A/INA 峰峰 | **5 码** | 该端口**未接**,死 |
| B/INB 峰峰 | **39 码** | 端口 B 接 DDS,**活的正弦** |
| OTR | 0 | 无溢出 |
| Cs | 12942.154 pF | ⚠️ **未标定**,只有相对意义 |
| 耗时 | 0.30 s(300 ms 驻留) | 与 `LLM-053` 在 65 MSPS 下测到的"无额外延迟"一致 |

### 4.4 屏上(与 4.3 同一次运行)

- 页面:**结果汇总 → 单点波形**;
- 偏压显示 `5.00 V`;
- 回路电流曲线:**干净正弦**,250 点里约 **3.85 个周期**
  (≈65 点/周期,与 65 MSPS / 1 MHz 相符 ⇒ **波形与档位自洽**);
- 状态:`已采集 250 点`。

⚠️ **同一页上方"激励与偏置电压(端口 A)"那张图看着顶到轨,不是故障** ——
它的 Y 轴按数据自适应(曲线注释为 `lo−8% … hi+8%`),
而该通道峰峰只有 **5 码(≈2.4 mV)** ⇒ 量程被缩到约 3 mV,视觉上就是满幅噪声。
📌 判别法:**看纵轴刻度值** —— 顶轨的是"一千九百九十几"(悬空满量程码),
这里顶轨的是毫伏级,两者完全不同。

## 五、触摸通路的两条观察(旁证)

1. **粘滞总线错标志**:日志里
   `[touch] PL 报过总线错(err 粘滞位置起,0x68=0x00000310)`。
   这是**历史累计**标志,只有重配 PL 才清 ⇒ **本次触摸仍然正常工作**(后续触点全部登记),
   不能拿它当"触摸坏了"的判据。
2. ⚠️ **触摸无法从 PS 侧注入**:`0x68/0x6C` 在 fabric 里是**只读**的。
   ⇒ 凡涉及触摸的验收**必须由用户手点**,模型只能准备环境 + 读证据。
   这使本次验收的自由度低于 ADC 那几组(那些可以脚本扫参数)。
