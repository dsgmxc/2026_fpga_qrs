# 2026-11-02 标准板单点反查 · 通道级校准残差

> 目的:校准采完之后,用**标准板 1 自己**做一次单点测量,看反演结果能不能回到它的
> 标称值。这是 B8(OPEN/SHORT/LOAD 校准残差)最直接的一张表。

## 条件

| 项 | 值 |
|---|---|
| 位流 | 自启加载,**本次上电恰 1 次**(`dmesg` `writing` = 1) |
| 固件 | `/proc/<pid>/exe` = `ed89168f00b5e7236a228f519cd77e4e`(含 `cal_channel_point`,即 `\|a−1\|` 守卫版) |
| 激励 / 采样 | 1.000 MHz / 32.50 MSPS(DIV=4,相位 +1) |
| 偏压 / 挡位 / 回路 | 0.10 V / **B(100 Ω)** / 单点「全部」(CISS → COSS → CRSS) |
| 被测件 | **标准板 1**:Cgs 1986 / Cgd 10 / Cds 104 pF,Rg 0 |
| 校准 | 16/16(当前频率),四挡全部 `L2*` |

## 结果

| 腿 | 标称(板 1 定义) | 实测 | 残差 | 实测 \|Z\| @1 MHz |
|---|---|---|---|---|
| CISS = Cgs + Cgd | **1996 pF** | **1995.788 pF** | **−0.21 pF(−0.01 %)** | 79.7 Ω |
| COSS = Cds + Cgd | **114 pF** | **116.690 pF** | **+2.69 pF(+2.4 %)** | 1364 Ω |
| CRSS = Cgd | **10 pF** | **12.120 pF** | **+2.12 pF(+21 %)** | 13131 Ω |

## 判读

- **CISS 几乎完美**(−0.01 %):它的 `|Z| = 79.7 Ω` 与 `R0 = 100 Ω` 同量级 —— 电桥最灵的位置。
- **COSS +2.4 %**:`|Z|/R0 ≈ 13.6`,已开始吃力。
- **CRSS +21 %(绝对 +2.12 pF)**:`|Z|/R0 ≈ 131`。**这不是新缺陷,是量程问题** ——
  10 pF@1 MHz 在 B 挡本来就在量程外,应该用 D 挡(10 kΩ)测;但 D 挡的通道系数
  被 `|a−1| ≤ 0.50` 守卫拒掉(那条拟合是外推伪解,见
  `20261029_channel_cal_verify.md` §一)。⇒ **CRSS 测小电容时残差偏大,是"无可用高档位"
  的直接后果**,与校准算法本身无关。
- 校准修正量本身很大(CRSS 原始 `Re = 1915 Ω` → `755 Ω`,`Im` 基本不动),
  这与 `a = 1.009 + 0.089j` 的复增益一致。
