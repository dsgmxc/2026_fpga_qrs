# rtl-constant-experiment-must-verify-netlist

> 当把某个 **RTL 常量**当作实验的自变量时:
> **源码不是证据,综合后的网表才是;位流 md5 也不是。**
> 本技能来自同一天内**两个方向的同一个错**。

## 适用范围

- 场景:**改一行常量 → 重新综合 → 上板 → 看行为变化**,用结论反推根因(二分法 / 单变量分离)。
- 工具:Vivado 2025.2,工程 + 批量模式。
- 适用于任何"用位流行为做实验"的调试流程。

**不适用**:纯仿真实验(仿真直接吃源码,没有这一层)。

---

## 使用方法

### 一、为什么源码和 md5 都不够

三样东西是**三个不同的东西**,不能互相替代:

| 层 | 它是什么 | 能不能证明"常量真的生效了" |
|---|---|---|
| **源码** `.v` | 你想让工具做的事 | ❌ 不能。综合可能没跑、可能跑了旧的 |
| **位流 md5** | 那个文件变了 | ❌ 不能。md5 只证明**它变了**,不证明**变的是我以为的那一处** |
| **综合后网表** | 工具**实际**做出来的电路 | ✅ **这才是证据** |

### 二、处方:核心网表,再上板

```tcl
open_checkpoint <proj>.runs/impl_1/system_wrapper_routed.dcp
write_verilog -mode timesim -force /tmp/netlist_check.v
```

然后在网表里**逐位**找到那处常量:

```verilog
// 例:检查 AXI 主机的属性位是否真的按预期接进去了
.S_AXI_HP0_ARPROT({…})      // ← 逐位读,不要只看有没有这个端口
.S_AXI_HP0_ARCACHE({…})
```

**固化成动作**:**每一次**改完常量、综合完、上板**之前**,先做这一步。

### 三、实验设计:单变量分离

如果要同时动两个常量,不要一次改一个值就上板 —— 做成 **2×2**,四格全测。
本项目实测样本:

| `ARCACHE` | `ARPROT` | 结果 |
|---|---|---|
| `0010` | `000` | ✅ 有数据 |
| `0011` | `000` | ✅ 有数据 |
| `0010` | `010` | ❌ DECERR |
| `0011` | `010` | ❌ DECERR |

⇒ **只由 `ARPROT` 决定,`ARCACHE` 完全无关。** 两格就能下的结论,四格才敢写。

**再加一步"交替加载"**:同一个 boot 内 A → B → A。若结果**跟着位流走、不跟板子状态走**,
再排除掉"板子粘滞"这类假设。

## 失效条件

- ⛔ **拿改过的源码当"实验自变量已生效"的证据** —— 这是本技能的全部理由。
- ⛔ **拿位流 md5 当"改动生效"的判据**。
  ⚠️ 尤其当**位流已被后续构建覆盖**时 —— 那次实验**无法复查**,
  基于它的结论只能**作废**,不能保留。
- ⛔ **只跑一格就下跨变量的结论。**
- ⛔ **上板一次就改一次**,没有网表核对 —— 出现异常时**分不清是常量没进、还是推断错了**。

## 已验证的效果

| 项 | 结果 | 证据 |
|---|---|---|
| 网表核对成为固定动作 | ✅ 本项目 2×2 四格实验**每格先核网表再上板** | `report/measurements/20261003_hp0_decerr_rootcause_arprot.md` |
| 2×2 单变量分离 | ✅ 四格全测,结论:`ARPROT[1]` 决定 DECERR,`ARCACHE` 无关 | 同上 |
| 交替加载 A/B/C | ✅ 同 boot 内 `a963(000)`→有数据、`298c(010)`→全零、`a963(000)`→有数据 ⇒ **跟位流走** | `LLM-036` 六步第 3 步 |
| 一次"以为没改其实进去了"被拦下 | ✅ 同一动作后续两轮均先核网表,未再复现 | `cv_sys.v` 注释 + 上述存档 §5 |

### 🔴 反面记录:两个方向的同一个错(同一天)

1. **"以为改了没进去"** —— 上一轮把某格实验的常量取值**从源码读的**,
   **从来没核过网表**;核过网表的只有另外两份位流。而这一格**已被后续构建覆盖,无法复查**。
   基于它写出的结论(「假设已被推翻」)**在下一轮被推翻**。
2. **"以为没改其实进去了"** —— 同一篇文档里,模型刚写下
   「**位流 md5 不是"改动是否生效"的合格判据**」,
   **转身又拿源码当"位流里是什么"的合格判据**。

> ⇒ 同一个坑的两个方向。**"我改了这个文件"与"这个常量进了电路"之间隔着一整条工具链。**
