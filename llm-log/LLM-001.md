## 纠错轨迹

**案例:模型把 AD9833 与 FPGA 的晶振频差问题严重高估了**

1. **模型错在哪**
   在早期讨论中,模型判断 AD9833 的独立板载晶振与 FPGA 晶振之间存在
   最坏 100 ppm 频差,断言这"会让测量结果不可用",并据此建议更换激励方案。

2. **怎么发现的**
   用户追问"为什么不能改晶振",模型重新推导解调输出的解析式:

   ```
   P = (A/2) · sinc(Δf·T) · e^{j(πΔf·T + φ)}
   ```

   发现这个含 Δf 的公共因子对**两路通道完全相同**(同一个 Δf、同一个积分窗 T),
   而本项目用的是**比值测量** `Z = R_ref · V_A / (V_src − V_A)`,
   两路相量一除,频差影响**精确抵消**。

3. **怎么改的**
   模型明确承认前一次判断错误("我原本判断这会毁掉测量 —— 重新推导后,
   结论要修正"),给出完整推导,并把结论从"不可用"改为:

   - 频差在比值中约掉 → **不影响阻抗测量**
   - 真实代价是 `sinc(Δf·T)` 的 SNR 损失
   - 由此导出真正的约束:**积分窗 T ≤ 1 ms**
   - 映射到设计参数:f_s = 20 MSPS → R = 20000 抽取值 → CIC N=2 时位宽 41 bit

4. **改完还有没有问题**
   有,而且要说清楚:**这次仍然只是理论推导,没有实测支撑**。
   推导里用的 ±50 ppm 是数据手册估算值,不是实测值。已在
   `docs/project_state.md` §六标注为"交付前必须补:频率计实测两晶振频差"。

   另:用户已决定暂缓处理频差(决策 D15),先按"认定无频差"推进主链路。
   这个暂缓是合理的排期选择,但**报告里 D11 的论证不能只停留在公式**,
   否则"我们用比值法消掉了频差"这句话经不起评委追问。
