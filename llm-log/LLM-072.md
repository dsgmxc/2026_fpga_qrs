## 模型回答

### 1. 数据筛选与参考模型

- 压缩包里有 **14 组**测量目录;`1`–`10` 是同型号的十颗器件(用户指定),`值钱/11`、`值钱/13`、`值钱/14`
  不用。三颗被排除者与典型曲线只差 1.4–2.5 %(中位),**再纳入会改动 Coss/Crss 拐点附近的值**,故不混入。
- 逐点取 **十颗的中位数**(不是均值 —— Coss/Crss 拐点有个别早跳变样本会拖均值);
  每条曲线的 Vds 是仪表实际读数,网格不统一,先按 `(log Vds, log C)` 插值到标称网格:
  **Vds 0.1 → 100 V,201 个对数等距点**;Rg 按 `(Vgs, Rg)` 插值,**−3 → +3 V,101 点**。
- 最接近典型值的单颗是 **7 号**(1–100 V 上 RMS 对数偏差 1.71 %),但它只作为记录,不改变"典型 = 中位"的定义。
- **Cp 不单独存表**:仪表给出的 Cs 与 D 是两列独立的中位数,若再对 Cp 单独取中位,
  三个数在同一个偏压点上会互相对不上(实测最大差 2.4 %)。改为运行时 `Cp = Cs / (1 + D²)`,
  使界面上同一行的 Cs/Cp/D **按构造自洽**。这一点写进了数据表和 README。
- 产出:`tools/make_th521_reference.py`(从归档 zip 重跑)+ `src/c_ui/app/ref_th521_data.{c,h}`
  + 只读访问层 `src/c_ui/app/ref_model.{c,h}` + 宿主单测 `src/c_ui/tests/test_ref_model.c`。

### 2. 界面

- **器件类型选择器**:文字取自 `RefModel_Name(model)`,遍历 `RefModel_Count()` —— 以后加型号
  只加表、不改 UI 调用方。
- **叠加开关** `叠加:开 / 叠加:关`:**同一份状态**驱动「扫压结果」与「扫压波形」两张图的参考曲线
  和两处「标准」图例;关掉时图例一起隐藏,避免图例指着不存在的线。
- **曲线区分**:参考线用**虚线 + 稍暗颜色 + 2 px**,实测线保持实线。CISS/COSS/CRSS 同一腿同色,
  靠线型区分测量与参考,不额外占用颜色维度。
- **单点结果**:每张腿卡在实测值下面加一行浅色参考值(Cs / Cp / D),RG 卡加「标准 Rg」;
  偏压未知时显示 `标准 --`,不猜。
- 提示语写明口径:`Cs 可直接对照;Cp/D 标准值不含线阻,实测值含线阻`。

### 3. 「TH521 是仪器,TK9J90T 是器件」

## 纠错轨迹

1. **LVGL 的 `dash_width/dash_gap` 只管横线与竖线**。第一版给 `lv_draw_line_dsc_t` 设了 dash 参数,
   斜线段却没有虚线效果 —— 读 `third_party/lvgl/src/draw/sw/lv_draw_sw_line.c` 发现按 hor / ver / skew
   分派,只有前两者处理 dash。改成**按弧长自己走虚线**(`UI_DrawDashedSegment`,5 on / 4 off),
   并把 dsc 的 dash 归零,避免两道裁剪叠加。
2. **我以为字体子集覆盖了所有 UI 字串,实际没有**。子集里**没有「比」「十」**;原稿「曲线对比」「十颗」
   在屏上会掉字。改词为「叠加」「10 颗」「对照」,并把所有真实 UI 字符串重新筛了一遍
   (日志里的 emoji 缺字不算 —— 那是 stderr,不上屏)。
3. **改名后按钮装不下**。`TK9J90T 标准(10 颗)` 在 cn_20 下宽 185.75 px,原标签区 182 px。
   选择器 202 → **210 px**、开关 116 → **110 px**,重排整行后不动其他控件。
4. **读板上瞬时状态时差点拿旧文件当新证据**。板上 `fb_dump.py` 已不在(`/home/xilinx` 没有),
   而第一次 `md5sum` 读到的是上一次遗留的 PPM(两块 md5 相同) —— 若不复核就把旧帧当成本次截图。
   改为**先删旧 PPM、再确认脚本存在、再 dump**,并核对输出里的颜色统计。
5. **板上 `sudo` 这次不是免密**(`sudo -n` 失败,报 "a terminal is required"),无 NOPASSWD。
   用 pty + `sudo -S -p ''` 喂出厂口令执行 dump;口令**没有落进任何文件或提交**。

## 沉淀

- 候选 `skill/vendor-widget-draws-only-some-orientations/`:**库文档说"支持虚线"不等于每条绘制路径都支持** ——
  验证要看**分派表**,并在目标几何(斜线)上实测。
- 扩展 `skill/stale-artifact-silent-reuse/`:第 6 种形态 —— **板上脚本丢失、旧输出文件仍在**,
  命令失败后 `md5sum` 照样给出一个值 ⇒ **先删产物再看新产物**,不看"文件存在"。
- 候选 `skill/derived-value-over-independent-median/`:**多列相关量逐列取中位会破坏恒等式** ——
  要么只存独立量、其余现算,要么接受显示不自洽;本项目选前者。
