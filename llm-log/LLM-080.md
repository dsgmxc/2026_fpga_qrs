## 一、为什么两块负载就够

误差模型是 Möbius:`Z_m = (a·Z_d + b)/(c·Z_d + 1)`。本夹具实测误差主要是一条
**乘法型复数误差**(`a` 为复数、`b ≈ 0`),所以退化成仿射也够用:

```
Z_m = a·Z_d + b        (c = 0)
```

- 只有 **一块**已知负载 ⇒ 一个方程,`a`、`b` 两个未知量 ⇒ **无解**(这正是 10-25 那轮
  「标准板校准 16/16 采集成功、拟合 0/16」的原因);
- **两块**已知负载 ⇒ 两对 `(Z_L, M_L)`:

```
a = (M_2 − M_1) / (Z_2 − Z_1)
b = M_1 − a·Z_1
```

⇒ **既不需要开路,也不需要短接**。

**间隔守卫**:`|Z_2 − Z_1| ≥ 5% × max(|Z_1|, |Z_2|)`(`CAL_LOAD_SEP_MIN`)。
两块板标称值太接近时两个方程几乎重合,硬解会把测量噪声放大 `1/间隔` 倍 ——
宁可显示"未标定",也不给一个数字好看但没有意义的反演。

**拟合路径优先级**(`refit_point()`):

```
1. OPEN + SHORT + LOAD   完整 Möbius
2. SHORT + LOAD          仿射(c=0)
3. LOAD1 + LOAD2         两点仿射(c=0)   ← 本次新增
4. OPEN + LOAD           b=0 的 Möbius
5. 仅 OPEN               平行杂散校正(a=1,b=0,c=1/M_o)
```

高优先级先试:SHORT 是精确 0 Ω,比"两个数据手册标称值"更可信;只有它不可用时才走两负载。

⚠️ **存盘格式升到 v2 ⇒ 旧 `cv_calibration.dat` 会被版本号拒掉**,板上升级后**必须重采**。
这是有意的:布局变了还"尽量兼容",读到错位的 double 比直接拒更危险。
