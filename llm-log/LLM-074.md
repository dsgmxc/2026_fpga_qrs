# LLM-074:三标准校准(OPEN / SHORT / 标准板)—— 分式线性误差模型 + 可输入的标准板参数 + 校准页

- **日期**: 2026-10-24
- **模型**: deepseek-flash(Claude Code harness)
- **任务**: 用户只有两样能测的东西(拔掉被测件 = OPEN、自制的"标准电容模拟 MOSFET"小 board),
  问怎么用这两组数据做校准;随后要求标准板的拓扑/容值/耐压**先做成可输入**,并增加
  **0 Ω 短接位**(接在 D-G-S 之间)和**已知电阻**。用户明确说标准板的最终取值"后面再决定"。

## 提示词

```
我确实打算做个校准页面的，我能测的东西有两个其实一个是空载下的数据
一个是我自己做了一个小板子用标准电容模拟mosfet你觉得应该怎么使用这些数据怎么校准比较好
```

```
标准板的拓扑和容值/耐压(几个电容、接在哪些管脚之间、耐压多少)？
这个先做成可输入的吧我后面再决定，能不能加一个 0 Ω 短接位和一个已知电阻
如果是接在漏栅原之间是可行的 空载就是直接拔掉
```

## 方案

**误差模型采用三标准分式线性变换(Möbius),不是"减一个偏移"。**

```
Z_m = (a·Z_d + b) / (c·Z_d + 1)
```

三个标准各自钉一个参数:

| 标准 | 物理操作 | 得到 |
|---|---|---|
| OPEN | 直接拔掉被测件(`Z_d → ∞`) | `a/c = M_o` |
| SHORT | 0 Ω 接 D-G-S(`Z_d = 0`) | `b = M_s` |
| LOAD | 标准板接 D-G-S | `c = (M_L − M_s) / (Z_L·(M_o − M_L))`,`a = c·M_o` |

反演:`Z_d = (m − b) / (a − c·m)`。OPEN 只有一路标准时不够(两个未知数一个方程),
所以坚持三标准;退化情形按可用性降级,并在拟合标记里体现:

| 可用的标准 | 路径 |
|---|---|
| OPEN + SHORT + LOAD | 完整 Möbius |
| SHORT + LOAD | 仿射(`c = 0`) |
| OPEN + LOAD | `b = 0` 的 Möbius |
| 只有 OPEN + SHORT | **不拟合**(标志位清零,应用时不修正)<br>⚠️ **已被 `LLM-075` 取代**:改为"仅开路平行杂散校正"(`a=1,b=0,c=1/M_o`,带四挡一致性闸) |

**标准板拓扑按数据手册定义拆成四腿**,每腿单独拟合(腿 = CISS / COSS / CRSS / RG):

```
CISS = Cgs + Cgd (串 Rg)    COSS = Cds + Cgd    CRSS = Cgd    RG = Rg
```

界面让用户输入 `Cgs / Cgd / Cds / Rg` 四个数 + 耐压 + 校准偏压,而不是输入阻抗 ——
器件封装里到底怎么接,用户自己可能也要改,直接输"几个电容接在哪"最不容易歧义。
一腿的 `Z_L` 由这四个数在运行时现算(StandardZ),频率取当前激励档(10k / 100k / 1M)。

**两道守卫(都是"宁可不信,不要算出一个漂亮的错数")**:

1. `CAL_OPEN_MIN_RATIO = 5.0`:开场实测与负载实测之比不足 5 倍 ⇒ 该点开路视为噪声底,退回仿射。
2. `CAL_EPS_REL = 1e-12`:拟合分母按相对量级判退化;反演时分母(`a − c·m`)退化 ⇒ 本点不应用校准。

**采集时序**:4 腿 × 4 挡 = 16 点/标准。挡位写 `0x18` 当拍生效,继电器只在换腿时切一次,
每次换腿后等一个驻留(300 ms)再采;状态机挂在 `DisplayProtocol_Process()` 里,
每 tick 只采一点,界面全程可响应。**用 `0x18` 的实际回读判断挡位**,回读与请求不符则该点标坏、不存。

## 纠错轨迹

| # | 事情 | 结论 |
|---|---|---|
| 1 | `_Static_assert` 按"头 60 B / 点 132 B"写,编译直接失败 | 实际 `packed` 布局是 **64 B / 100 B**(点 = 4 + 12×8,不是 16 个 double)。用 `/tmp/sz.c` 打出实测大小后改断言与注释 |
| 2 | 进度条用 `lv_bar_create()` | 本工程的 `app/lv_conf.h` 里 **`LV_USE_BAR 0`**;改为"轨道 panel + 填充 panel,按比例改宽",不为一行进度条全局打开一个新控件 |
| 3 | 新页面的中文在屏上会**静默变空白** | 字体是子集;扫出 UI/日志字面量里缺的 44 个字(倍像剩匹受吗套小属嵌差干平建弱律想折抢拍拔损推支暂更极栅校死比盘短秒穷符缺考者耐记镜陷靠),重新生成两份字体并逐一核对 |
| 4 | 校准完成日志写"拟合 48/48" | `EndStandard()` 返回的是**全频段**累计;本频率应是 `FittedCount(idx)`。改为两个数都打:本频率 x/16、全部 y/48 |
| 5 | 校准采集期间 `VL/VH` 低比例警告刷屏 | 那是测标准件时的正常读数,加 `!s_cal_capture_active` 抑制;常规测量时仍保留 |
| 6 | 单测首版直接调 `Apply()` 处处返回 false | **默认是"未启用"**(`s_enabled = 0`),开关由 `Calibration_Init()` / UI 切换。测试改为显式 `Init()` 并**把"默认关"这条钉成断言** |
| 7 | 单测里 CRSS 腿反演不回来,而手算明明精确 | **不是代码错,是测试模型撞上守卫**:c 取 `1e-4+1e-5j` 时该腿实测开路/负载比只有 **3.4 倍 < 5**,开路被拒、退回仿射,于是丢了 `c` 那一项。改用 c 小一档的主用例,并**单开一个守卫用例**把"只有该腿掉精度、其余三腿精确"钉住 |
| 8 | 存盘失败时 `%s` 可能截断 / `getenv` 隐式声明 | 补 `<stdlib.h>`;诊断信息改用 `%.120s`。整机 `make -j2` 零告警 |
| 9 | **上板后校准页六格里显示 `f pF` / `f Ω` / `f V`,数值整段消失** | 根因:`app/lv_conf.h` 里 **`LV_SPRINTF_USE_FLOAT = 0`**,LVGL 的 `lv_snprintf()` 不支持 `%f`,把 `%.3f` 渲染成 `f`。**宿主单测覆盖不到显示层,只有抓帧能看见**。改成"整数 + 固定小数位"手工拼接(`UI_CalFormatNumber`,与工程其它页面同法),6 处全改 |
| 10 | 修完显示要重新上板,但服务重启 = 第二次 `Overlay()` | 走**软重启**(`sudo reboot`,等价一次上电、PL 重新加载);本周期位流仍只加载 1 次 |

第 7 条是这轮最值得留的:**测试失败先怀疑测试本身**(数据落在守卫边界上),
确认代码行为是设计意图后再改测试 —— 而不是把守卫放宽去迁就测试数据。

## 结果

⚠️ **部分可用** —— 数学与存盘已用宿主单测坐实;**界面、输入、存盘已在板上验证**;
**采集状态机(OPEN/SHORT/LOAD)仍零板上验证**。当前不可用于出报告数据,必须先走一遍:

1. 上电(用户),**一次上电只加载一次位流**;`qrs-ui.service` 保持 disabled,手工启动;
2. 先进校准页填标准板参数(Cgs/Cgd/Cds/Rg/耐压),四个数任一为 0 时对应腿会显示未定义;
3. OPEN:拔掉被测件 → 按「开路」;SHORT:0 Ω 接 D-G-S → 按「短接」;LOAD:接标准板 → 按「标准板」;
4. 看日志 `[cal]` 行:每标准 16/16,回读挡位与请求一致;再看覆盖表是否 16 格全绿;
5. 接已知器件,对比校准前后 `Cs/Cp/D`,并记录残差(B8 的素材)。

## 沉淀

- 候选 `skill/calibrate-with-standards-not-offsets/`:先把误差写成**分式线性**,
  再用"开路 + 短路 + 一个已知负载"三个可测点钉参数;三个都缺一不可,
  降级路径要写进标志位,不要让"拟合成功"掩盖"少一个标准"。
- 候选 `skill/test-data-must-respect-guards/`:单测数据要覆盖守卫边界 ——
  否则一次"代码没错、测试错"的失败很容易被误判成代码缺陷,反过来把守卫改松。
