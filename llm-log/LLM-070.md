## 纠错轨迹

1. **SCV1 不是任意点。** 最初打算把实测点直接编码,读 `sweep-codec.js` 后发现解码器**不传电压表**,
   而是按 start/stop 重建隐式网格(`i*20/60`,再补整数,最后替换首点)。
   ⇒ 改为在 C 侧按同一规则生成网格并做 log-log 重采样;否则解码端电压全错。
2. **Float16 下限。** 前序的 `1e-8 nC` 在 Float16 下变成 0(次正规数最小约 6e-8)。
   ⇒ 改为 `1e-6 nC`,并在文档里写明。
3. **结果页探针函数写死 `g_sweep_chart`。** 首次编译通过前发现结果页触摸会驱动扫压页的图表;
   ⇒ 把 `UI_SelectSweepProbe` / `UI_SelectInterpolatedSweepProbe` 参数化为 `(chart, owner)`。
4. **全局变量定义顺序。** `UI_ResultsSweepTouchEvent` 在 `g_results_chart` 定义之前引用,编译报
   `undeclared`;`g_results_summary_label` 同样。⇒ 在文件前部补文件作用域声明。
5. **单测预期偏离。** 原计划"让一个点无效 ⇒ SCV1 valid 位为 0"不成立:PCHIP 重采样会对每个网格点求值,
   单点无效不会产生无效网格点。⇒ 测试改为断言"仍能完整解码",并在计划记录里如实保留差异。
6. **`LV_FONT_MONTSERRAT_20` 未启用。** 参数卡数值改用已启用的 `montserrat_24`。
7. **子集字体缺字 —— 屏幕静默丢字。** 第一轮上板截图里「分析电压」显示成「分电压」,
   「实测数据二维码」缺「维」;`ui_font_cn_20/28.c` 是按固定符号表生成的子集,
   LVGL 遇到缺字**不报错、渲染空白**。⇒ 扫描 C 字符串字面量(排除注释)与字体 cmap 比对,
   用系统 `NotoSansCJK-Regular.ttc` 的 SC 面 + 原参数重新生成,605 → 670 码位。
8. **结果页摘要在 350 px 内放不下。** 原文案「每路点数 N    有效曲线 x/3    最近一次 RG --」
   在截图右端被裁掉 `RG --`;面板右上只剩 350 px(再宽会压到图例)。
   ⇒ 缩短为「每路点数 N · 有效曲线 x/3 · RG --」,实测完整显示。
9. **`fb_dump.py` 没有执行位。** 直接 `sudo /home/xilinx/fb_dump.py` 报 command not found
   (权限 `-rw-rw-r--`)。改为 `python3 /home/xilinx/fb_dump.py` 即可,不改文件权限。
10. **板上源码树分 `app/`、`ui/` 子目录。** 第一次把 3 个文件按 basename 传到
   `/home/xilinx/c_ui_src/` 根目录,板上 `make` 报 "Nothing to be done" —— 根目录文件不在
   `wildcard app/*.c ui/*.c` 里。⇒ 改传到 `ui/`,并删掉根目录误放的副本。

## 沉淀

- 协议移植的通用教训:**先读解码器,再写编码器**;点集/网格这类"隐式约定"要写成可交叉验证的单测。
- 十六进制浮点格式(Float16)的边界值要用实际编码器回读确认,不能按 float32 直觉设下限。
- **子集字体的缺字不会报错。** 改中文 UI 文案后必须把「字符串字面量集合」与字体 cmap 做差集,
  再重生成;这一条应写进任何 LVGL + 自定义字体的检查清单。
- **屏上产物要能自己回读验证**:二维码截图用 jsQR 解回文本、与实际载荷比 md5,
  比"看起来像二维码"强得多。
